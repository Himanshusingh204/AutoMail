# Changelog

## 0.2.0
- `draftbox hotkey`: Ctrl+Alt+D reads the mail on screen and shows an editable draft (Windows, Mac, Linux).
- Engines: `auto` (logged-in claude CLI, else local Ollama), `claude`, `ollama`, `gemini` (explicit only). Switch and Redo from the window.
- `examples.md` for tone, F8 "Open in mail app" (still never sends).
- Draft window: scrollbar, hand editing, **Change request + Redo** (shorter / more formal / say no politely), status line; Mac notifications; Mac hotkey Ctrl+Shift+D.
- CI on Windows, Mac and Linux; every window button has a test.

## 0.1.0
- Gmail + Outlook draft-only providers, demo mode, review page, triage, injection tests, golden set, style learning, purge, stats, notifications.
